## 제1원리 요약
"n = p + q"의 존재는 ① 소수 밀도(1/ln)와 ② 소수 간 상관으로 결정된다.
밀도는 넘친다(기대 분할 수 n/ln²n → 발산). **골드바흐가 거짓이려면
밀도가 아니라 상관이 음모를 꾸며야 한다.** 모든 가설은 이 음모를 조준한다.

### H1. 스펙 설정 — "r(n) < 3.4·ln²n" ☠️ 사망 (10⁸ 사냥)
- 사인: n = 37,998,938에서 r=1039, 비율 3.411로 스펙 돌파. 비율이 단조 상승 중이었음(1.0→3.4).
- 유산: ln²n 스케일이 틀렸다는 확정 → H1′ 승계.

### H1′. 스펙 수정 — "r(n) < 1.25·ln²n·lnln n" 🟢 생존 (H1 후계)
- 근거: 최근 9개 챔피언(n=5×10⁵~6×10⁷, 두 자릿수 규모 확장)에서
  r/(ln²n·lnln n) = 1.13~1.20으로 **평탄**. 기어오름 소멸.
- 킬 조건: 더 큰 범위에서 1.25 돌파. 다음 시험: 10⁹ 사냥.
- 의미: 이 상계 하나가 증명되면 골드바흐 완료. (문헌의 Granville 휴리스틱과 동형)

### H2. 서식지 — "챔피언은 얇은 띠에만 산다" 🟢 생존
- 기록: 10⁸까지 챔피언 26/26 전원 3∤n (n>30 기준). 신규 4명(2.4×10⁷~6×10⁷)도 전원 준수.
- 구조 근거: 우리가 증명한 띠 골격 정리(3|n이면 분할 수 2배)와 정합 —
  최악 사례는 방어가 얇은 곳에서만 발생.
- 킬 조건: 3의 배수 챔피언 1개.

### H3. 질량 보존 — "결핍은 이웃이 보상한다" ☠️ 사망
- 사인: 실측 이웃 상관 +0.23~+0.62 (보상 아닌 공모). 21창 분산 = 독립 가정의 6~12배.
- 원인: 이웃 짝수들이 [n/2, n] 구간 소수 밀도를 공유.
- 유산: 공모 진폭이 ±3.4%에 불과 → H3′ 승계.

### H3′. 음모 진폭 감쇠 🟢 생존 (H3 후계) — **라운드 1 최대 수확**
- 실측: σ(z)가 지수 −0.376으로 감쇠 (포아송 −0.5에 근접).
  게다가 실측 요동은 포아송의 절반(초과비 0.48~0.57, **준포아송**) — 소수는
  랜덤보다 더 규칙적으로 분할을 공급한다.
- 반례 도달 거리: n~10⁴에서 27σ → n~10⁵에서 61σ → n~5×10⁵에서 **110σ**.
  역대 최심 결핍은 4.3σ. 필요 음모는 커지고 음모의 힘은 줄어든다.
- 킬 조건: 더 큰 규모에서 초과 요동(감쇠 정체) 발견.

### H4. 음모 예산 — "커버리지는 구조적으로 100% 미달" 🟢 생존
- 무오차 골격: n^{1/3}-체 생존자는 소수 아니면 P2 (정확한 사실).
  반례가 되려면 생존자 전원이 P2여야 한다.
- 실측 (규모별 30표본, 얇은 띠): 생존자 최소 143(10⁴) → 47,720(10⁷) — 0에서 발산 중.
  생존자 중 소수 비율 67% → 60.7%로 **안정** (붕괴 추세 없음).
- 의미: '전원 P2 절벽'은 60%를 0%로 만들어야 하는데 비율이 움직이지 않는다.
  이 비율을 이론으로 강제 못 하는 것 = **패리티 장벽** = 증명의 벽의 정확한 좌표.

### H5. 부품 삭제 — "소수성은 부품이 아니다" 🟢 생존
- 실측: 크라메르 랜덤 세계 200개(밀도 1/ln m만 부여, N=10⁶).
  n > 1,276 반례 전무. 최대 실패 n 중앙값 300, 99분위 1,172.
- 의미: 골드바흐의 성립에 소수의 깊은 성질은 불필요 — **밀도와 유사랜덤성이 전부**.
  증명 과제는 "소수가 충분히 유사랜덤함"의 입증으로 축소된다 (이게 어렵지만).
- 킬 조건: 더 큰 N에서 랜덤 세계 반례 출현 (N=10⁷, 세계 1000개로 재시험 예정).

## Q3′ 최종 유도 완료 (2026-08-03, 정본: Q3_DERIVATION.md) — 세션의 정점
- **분해 항등식** R = (n−1) + 2Δψ + Q 수치 검증(10⁻⁸); Var의 99.8% = Q̃(영점 쌍 간섭).
- **유도 사슬**: Q̃ = Σ B(ρ,ρ′)n^{i(γ+γ′)} → 반대부호 쌍 지수 소멸(|Γ(½+it)|²=π/cosh πt)
  → 같은부호 쌍 |B|²=2π/(γ+γ′) → 밀도 적분 ∫∫dsdt/(s+t) = **2 ln 2** (덧셈의 베타-기하)
  → 합 법칙 컷오프 T≈πn → **억제 상수 후보 ln 2 = 0.6931**.
- **측정 행진**: 순수요동 극한이 데이터 확장마다 0.633 → 0.665 → 0.677로
  ln 2를 향해 단조 접근 (12옥타브, 2²³=1,680만). HL-기준은 위에서(0.69→0.73) — 협공.
- **추측 등재**: "골드바흐 준포아송 상수(σ) = ln 2" — RH 휴리스틱 유도 + 측정 협공.
  미해결: √ 부기 1개, GUE 쌍상관 보정항. 반증 조건: 대규모에서 극한 이탈.
- 부수: 교차 파이프라인 검증으로 2C₂/C₂ 계수 버그 검출(세 번째) — 상호검증 방법론 유효.
