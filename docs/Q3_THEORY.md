# Q3 이론 유도 기록 — 준포아송 상수의 기원 추적 (2026-08-03)

## 질문
골드바흐 분할 수 g(n)의 요동이 매칭된 랜덤 모델보다 작은(준포아송) 이유는?

## 방법론적 함정 4개 (모두 자력 발견·수정)
1. **산술 4점 모델의 구조 이중계상** — ℓ=3 인자 1.5는 요동이 아니라 띠 구조
   (μ에 이미 흡수됨). 올바른 조건화 후 산술 모델 예측 = 포아송. → v1 폐기
2. **이동평균 정규화의 장파장 흡수** — 강성이 작용하는 성분을 추정 전에 제거해버림
3. **추정량의 스케일 비불변** — 기대값 모델이 k배 틀리면 비율도 k배 왜곡
4. **J=0 지터의 형태 모델 불일치** — 특이급수 구조를 모르는 형태로 재면 27배 폭발

## 최종 방법: 스케일 불변 추정량 + 대칭 4세계 비교
z = g/형태모델 → 표본평균 재조정 → 드리프트 제거 → 비율 = σ(z)·√ḡ

| 세계 | 구조 | 비율 |
|---|---|---|
| W2 순수 크라메르 | 없음 (독립 베르누이) | 0.861 |
| W3 바퀴 mod 30 | 잉여류만 | 0.890 |
| W4 단일 강성 h=5000 | 블록 개수 고정 | 0.851 |
| W5 계층 강성 (5단 중첩) | 전 스케일 개수 고정 | 0.877 |
| **W1 실제 소수** | 전부 | **0.554** |

**분산비 (0.554/0.861)² ≈ 0.41** — HL2 정규화 독립 측정(0.45)과 일치. 실재 확정.

## 소거 결과
- 잉여류(산술) 구조: 기여 없음 (W3 ≈ W2)
- 개수 강성: 어느 스케일 조합에도 기여 없음 (W4, W5 ≈ W2)
- **지터 분광**: 실제 소수를 ±J로 흔들면 J=16 (≈ 평균 간격 1.2배)에서
  억제가 완전히 사라짐 (0.554 → 0.892 ≈ 랜덤 수준)

## 결론 (Q3′ — 정밀화된 가설)
준포아송 억제(분산 0.41×)의 기원은:
- ~~창 개수의 강성~~ (소거)
- ~~잉여류 상관~~ (소거)
- **평균 간격 ~1.2배 이하의 초근거리 배치 상관** — 베르누이-given-잉여류
  모델(HL 독립 휴리스틱)을 넘어서는 실제 소수의 미세 규칙성

이는 "소수는 HL 쌍상관+독립"이라는 표준 휴리스틱보다 실제 소수가
**더 규칙적**임을 시사하는 실측. 이 스케일(간격 오더)의 상관을 지배하는
이론 장치가 정확히 명시공식의 영점 간섭항(몽고메리 쌍상관/GUE 사인 커널의
영역)이므로, Q3의 최종 형태는:

> **Q3′ (이론 과제)**: 명시공식으로 g(n)의 요동을 영점 합으로 전개하면
> 간격-스케일 상관에서 분산 억제 인자 ≈ 0.41이 유도된다.

수치 증거 사슬: Q2(창 개수의 GUE 강성, 실측) + 지터 스케일 특정(≤16) +
전 랜덤 모델 소거. 남은 것은 해석적 유도 — 진짜 연구 문제.

## 부수 성과
- H3′ 재해석: "준포아송" 주장 자체는 생존하되, 올바른 기준선은
  포아송 1.0이 아니라 매칭-베르누이(같은 추정량) — 억제 인자 0.41로 정밀화.
- 추정량 방법론 확립 (앞으로의 모든 요동 측정에 적용할 표준).

# Q3′ 해석적 유도 (2026-08-03 속행)

## 1부 — 골드바흐 분광학: 수치 증명 완성 ✅

이론 (Fujii): Σ_{n≤x} R(n) = x²/2 − 2Σ_ρ x^{ρ+1}/(ρ(ρ+1)) + O(x ln³x)
— 골드바흐 총합 요동은 문자 그대로 리만 영점 파동의 합.

실측 (N = 2×10⁶, Λ-가중 R을 FFT로 전량 계산):
- **스펙트럼 피크 검출**: 골드바흐 데이터의 ln x-푸리에 스펙트럼 피크가
  γ = 14.079, 21.044, 25.046 — 리만 영점(14.1347, 21.0220, 25.0109)과
  오차 ±0.06 이내 일치. **골드바흐 데이터에서 리만 영점을 직접 검출.**
- **자유 매개변수 0개 재구성**: 영점 30개로 h(u)를 이론 계수·위상 그대로
  재구성 → 실측과 상관계수 **0.9771**, 진폭비 **1.020**.
  (여담: 처음 진폭비 2.04가 나왔는데 켤레 영점 쌍 누락으로 판명 —
  수정하니 2% 이내 일치. 이론이 스스로 버그를 찾아준 사례.)

## 2부 — 분산 회계: 미해결 명제의 정확한 주소

옥타브 [2²⁰, 1.75×2²⁰), F(n) = R(n) − n𝔖(n):
- 장파장(ζ-영점 대역, γ ≤ 101) 몫 = **0.1%** — 점별 예측 8n·Σ1/|ρ|² 대비 1.34배
  (잔여 = γ > 101 영점 + 필터 누출) → ζ-영점이 정량적으로도 설명.
- 단파장(간격 스케일) 몫 = **99.8%** — 지터 분광이 지목한 바로 그 대역.
- 매칭 Λ-베르누이 기준 대비 억제비: 총 **0.327** (비가중 측정 0.41과 동급),
  전부 단파장에 거주.

## 최종 결론 — Q3′의 완성형

> **[수치 증명됨]** 골드바흐 요동의 장파장 성분 = 리만 ζ-영점 파동
> (피크 위치·상관 0.98·진폭 1.02 — 자유 매개변수 없음).
>
> **[정확한 미해결 명제]** 단파장(소수 간격 스케일) 분산의 억제 인자
> ≈ 0.33~0.41을 디리클레 L-함수 영점(mod q)의 간섭으로 유도하라.
> 이는 GRH + 영점 쌍상관(몽고메리)급 입력을 요구하는 진짜 연구 문제이며,
> '골드바흐 방어선의 마지막 층 = L-영점 스펙트럼의 강성'이라는
> 정확한 사전(dictionary)이 이번 세션의 최종 산출물이다.

## 2단계 — 디리클레 L-영점 분광 (2026-08-03) ✅

**위상 태깅 설계**: F_q(x) = Σ_{a+b≤x} Λ(a)Λ(b)e(b/q) — 골드바흐 쌍의
한쪽 다리에만 위상을 걸면 주항 계수가 μ(q)/φ(q). **q=4는 μ(4)=0이라
주항이 소멸 → ζ-오염 없는 순수 L-영점 신호** (설계 예측).

결과:
| q | 골드바흐 경로 | 소수 직접 경로(ψ_χ) | 문헌 앵커 |
|---|---|---|---|
| 4 | 6.076 | 6.076 | L(χ₄) 6.0209 ✅ (+ζ 부재 적중) |
| 3 | 8.003 | 8.003 | L(χ₃) 8.0397 ✅ |

두 독립 경로의 완전 일치로 자기완결 검증. **골드바흐 데이터에서
ζ-영점(1부)에 이어 디리클레 L-영점까지 검출** — "요동 = {ζ(q=1)} ∪
{L(q≥3)} 영점 파동"의 사전이 실증됨.

**정직한 위치 확인**: 후지이 정리(1991)와 산술진행판 확장은 기존 수학
(우리는 검증·검출 시연). 우리 고유 기여는 ①미증명 영역의 정량 지도
(4세계 소거, 지터 분광, 억제 상수 0.33~0.41의 단파장 국소화)와
②그 대역의 주인이 L-영점임을 데이터로 지목한 것. **억제 상수의 유도
자체는 여전히 미증명** — 이것이 Q3′ 3단계(조건부 유도) 과제.
