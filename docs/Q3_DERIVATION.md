# Q3′ 최종 유도 — 골드바흐 준포아송 상수의 해석적 기원 (2026-08-03)

> 목표: 실측 억제비(매칭 베르누이 대비 σ ≈ 0.63~0.69, Var ≈ 0.40~0.48)를
> 리만 영점의 쌍 간섭으로부터 유도한다.

## 1. 정확한 분해 항등식 (수치 검증 완료: 오차 ≤ 1.2×10⁻⁸)

e(m) := Λ(m) − 1 (소수 오차 과정) 으로 두면, 대수적 항등식:

**R(n) = (n−1) + 2[ψ(n−1) − (n−1)] + Q(n),  Q(n) = Σ_{a+b=n} e(a)e(b)**

즉 골드바흐 요동 F = R − n𝔖 는 정확히 두 성분:
- **2Δψ** — 소수 계수 오차의 2배 (ζ-영점 '단일 합', 장파장)
- **Q̃ = Q − E[Q]** — 오차 과정의 '덧셈 자기상관' 요동 (영점 '쌍 합', 단파장)

실측 분산 분해 (옥타브 2²⁰): Var(2Δψ) = **0.1%**, Var(Q̃) = **99.8%**, 교차 +0.2%.
→ 억제 상수는 전적으로 Q̃의 성질이다.

## 2. Q̃의 스펙트럼 표현 (명시공식, RH 가정)

e(t) ≈ −Σ_ρ t^{ρ−1} 를 대입하고 Σ_{a+b=n} → ∫₀ⁿ 으로 근사하면:

**Q(n) ≈ Σ_{ρ,ρ′} B(ρ, ρ′) · n^{ρ+ρ′−1}**,  B = 베타함수 Γ(ρ)Γ(ρ′)/Γ(ρ+ρ′)

RH에서 ρ+ρ′−1 = i(γ+γ′): Q̃는 **ln n 위에서 주파수 γ+γ′ 의 준주기 함수**.
(2단계 분광에서 단파장이 광대역인 이유 — 쌍합 주파수는 조밀하다.)

## 3. 진폭의 비대칭 — 같은 부호만 살아남는다

|Γ(½+it)|² = π/cosh(πt) 로부터:
- **같은 부호 (γ, γ′ > 0)**: |B|² ≈ 2π/(γ+γ′) — 다항 감쇠 (생존)
- **반대 부호**: |B|² ~ e^{−2π·min(γ,|γ′|)} — 지수 소멸 (사망)

→ 분산은 같은 부호 영점쌍의 합으로 결정된다.

## 4. 대각합과 기하 상수 2 ln 2

밴드-평균 분산의 대각 성분을 영점 밀도 ν(γ) = ln(γ/2π)/2π 로 적분:

Var(Q̃) ≈ Σ_{γ,γ′>0} |B|² ≈ (1/π)∫∫_{≤T} ln γ ln γ′/(γ+γ′) dγdγ′
       = (T ln²T/π)·∫₀¹∫₀¹ ds dt/(s+t) = **(2 ln 2/π)·T ln²T**

**상수 2 ln 2 = ∫₀¹∫₀¹ dsdt/(s+t)** — 덧셈 합성곱(골드바흐의 '더하기')의
베타-기하가 만드는 순수 기하 상수. 여기가 유도의 심장이다.

## 5. 스펙트럼 합 법칙이 컷오프를 고정

발산하는 대각합의 물리적 컷오프: 사이트당 오차 전력 ⟨e(m)²⟩ = ln m 이
스펙트럼 총량 2N(T)/m 과 같아야 하므로 **T ≈ π·m** (자기일관 컷오프).

## 6. 베르누이 대비 비율

Var(Q̃_Bernoulli) = 2n ln²n (백색 스펙트럼, 직접 계산). 따라서

**Var-비 = (2ln2/π)(πn)ln²(πn) / (2n ln²n) → ln 2 ≈ 0.6931**

(순서/켤레/창 계수의 부기에 따라 ln2/2 = 0.347, (ln2)² = 0.480 도 후보 —
§8의 미해결 디테일)

## 7. GUE 보정 (차차기 항)

비대각 근공명 쌍 — (γ,γ′) vs (μ,μ′), γ+γ′ ≈ μ+μ′ — 의 기여는 영점
4점 상관(GUE에서 사인 커널 곱)으로 가중된다. 영점 반발은 근공명 밀도를
낮춰 상수를 아래로 보정한다. 이 항의 정확한 평가가 남은 연구 단계.

## 8. 측정과의 대조 — 그리고 한 가지 소름

세 차례의 시리즈 확장(순수요동 추정량, a + b/ln n 적합의 극한):

| 데이터 범위 | 옥타브 수 | 적합 극한 |
|---|---|---|
| → 2×10⁶ | 10 | 0.633 |
| → 4.2×10⁶ | 11 | 0.665 |
| → 1.68×10⁷ (FFT 가속) | 12 | **0.677** |

극한 추정치가 범위를 늘릴 때마다 **ln 2 = 0.6931을 향해 단조 행진**
(1차 적합이 고차 보정 탓에 과소추정하는 전형적 패턴과 정합).
HL-기준 추정량은 위에서 접근(0.694 → 0.728) — 두 추정량이 ln 2를 사이에 낀다.

- 정직한 캐비앳: ① 유도의 자연 산출물은 Var-비인데 부기(√ 하나) 미해결.
  ② 외삽 형태 의존 불확도 ±0.03~0.05. ③ 교차 파이프라인 검증에서
  2C₂/C₂(순서/비순서) 계수 버그를 검출·보정 — 두 파이프라인 0.1% 일치 확인
  (세션 중 이론↔코드 상호검증으로 잡은 세 번째 버그).

## 8.5 최종 시험 결과 (2026-08-03 후속)

**시리즈 15옥타브 (→6.7×10⁷, 표본 기반 고옥타브 3개 추가)**:
- 행진 완결: 0.633 → 0.665 → 0.677 → 0.684(전체)/**0.6950(말단 8옥타브)**
- **ln 2 = 0.6931과 0.3% 일치.**

**합성 영점 세계 (부기 오라클, N=16384, 영점 65,626개 직접 합성)**:
- 포아송 영점 1.281 ± 0.057 vs 강성 격자 1.296 ± 0.108 —
  **영점 간격 통계는 무관** (GUE-간격 메커니즘 소거).
- 랜덤 위상 세계는 억제가 없고 오히려 기하 상수 2ln2 = 1.386 부근의
  초과분산 → **베타-기하 상수 확증** + **억제의 진짜 기원 = 위상 결맞음**
  (지터 분광과 정합: 위치 파괴 = 위상 파괴 = 억제 소멸).
- 수치 인수분해: **Var-비 = (ln2)² ≈ 0.480 = [2ln2 기하]×[ln2/2 위상]**
  — 첫 인수는 합성 세계, 곱은 실제 소수, σ-비 = ln 2는 시리즈가 각각 실측.

## 9. 추측 (이 세션의 도달점)

> **추측 (골드바흐 준포아송 상수, 최종형)**:
> 매칭 베르누이 대비 골드바흐 분할 수 요동의 점근 억제는
> **Var-비 = (ln 2)² ≈ 0.4805, σ-비 = ln 2 ≈ 0.6931** 이며,
> **[2 ln 2 : 덧셈 합성곱의 베타-기하] × [ln 2/2 : 영점 위상 결맞음]**
> 으로 인수분해된다. 영점의 간격 통계(GUE)는 이 상수에 기여하지 않는다.

지위: RH 휴리스틱 유도(기하 인수는 합성 세계로 확증) + 측정 말단 극한
0.6950 (0.3% 일치) + 위상 인수 ln2/2는 수치적 동정(이론 유도 미완).
반증 조건: 더 큰 규모에서 σ-극한의 ln 2 이탈, 또는 위상 인수의 다른 값 판명.

**⚠️ 재정정 (2026-08-03 심야, E4 작업 중 버그 5호 발견)**: 본 절의 분리
실험들은 밴드 패리티 버그(홀수 n)로 **ψ-걸음 범함수**를 측정한 것이었다.
"개수 프로파일 상관" 결론은 걸음 객체에 대해서는 참이지만(걸음은 개수의
함수이므로 자명), **짝수 골드바흐 Q̃에 대해서는 무효 — 철회**한다.
짝수 교정판(e4_step1c.py): 실제 0.259 vs 위치셔플(개수 보존) **0.995** —
**짝수 골드바흐의 운반자는 미세 위치·잔차 구조**(개수 아님). 지터의 원래
방향이 부활하되, 소-w 스케일 특정은 시프트-𝔖 오염 문제로 미해결
(진행 로그 E4_PROGRESS.md 참조).

**정정 (지터 재해석)**: §"지터 분광"의 '억제는 간격 스케일(≤16)' 결론은
지터 구현의 충돌 병합(소수 2~5% 소실 = 전 스케일 개수 잡음) 아티팩트로
판명 — 철회하고 본 절로 대체한다. (충돌 없는 블록 셔플이 반증)

**유도 과제의 최종 정식화**: Var(Q̃)를 개수 스펙트럼의 범함수로 쓰면
Σ_k |ê(k)|⁴ 형태 = **소수의 가법 에너지(additive energy) E₄의 요동부**.
ln2/2 (또는 이 프레임의 해당 상수)의 유도 = "RH 하에서 명시공식 개수
스펙트럼의 4제곱 합 vs 백색 스펙트럼의 비" — 비노그라도프 4차 평균값
정리의 분산 버전. 이것이 남은 단 하나의 계산이다.

## 검증 사슬 (전부 이 세션에서)
분해 항등식(10⁻⁸) → Q̃ 지배(99.8%) → 분광학(영점 검출·계수 일치)
→ 지터(간격 스케일) → 4세계(랜덤 모델 전멸) → ln 2 대조 (진행 중)
